Adminul mai are nevoie de o setare

Fă pașii de mai jos o singură dată în Cloudflare, apoi urcă din nou site-ul (zip-ul) și reîncarcă această pagină.

  1. Spațiu de stocare. Storage & Databases → Workers KV → Create instance, cu numele tudormirca-date. Apoi Workers & Pages → tudormirca → Settings → Bindings → Add → KV namespace, cu Variable name SITE.
  2. Parola. Workers & Pages → tudormirca → Settings → Variables and Secrets → Add → tipul Secret (sau bifa Encrypt), nume ADMIN_PASSWORD, iar la valoare parola ta.
  3. Urcă din nou site-ul (Deployments → Create deployment), ca setările să intre în vigoare.
